# Portfolio — Amanullah Panhwar

A single-page portfolio site: Android developer & IT educator, featuring the Vasooli and Waqt apps.

## What's in this repo
- `index.html` — the homepage (hero, about, apps, roadmap, skills, experience, education, contact)
- `projects.html` — a dedicated, animated page listing completed projects, linked from the homepage nav
- `README.md` — this file

## Before you publish
Search the file for these placeholders and swap in your real links:
- `github.com/yourusername` (footer) — your GitHub profile
- The two `View repository` links under Vasooli and Waqt — link to each app's repo once it's public
- The `Play Store — coming soon` labels — replace with real Play Store links once each app is live

## Deploying to GitHub Pages
1. Create a new GitHub repo (e.g. `yourusername.github.io` for a root domain site, or any name for a project site).
2. Upload `index.html`, `projects.html`, and this `README.md` to the repo — commit to the `main` branch.
3. Go to the repo's **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to "Deploy from a branch", branch `main`, folder `/ (root)`.
5. Save. GitHub will give you a live URL within a minute or two (usually `https://yourusername.github.io/repo-name/`).

## Editing later
Everything — colors, fonts, copy, sections — lives in the single `index.html` file. Colors are defined once at the top of the `<style>` block under `:root`, so you can restyle the whole site by changing a handful of hex values there.
